# SkillForge Product Overview

## Product Vision

SkillForge is a platform for developers and self-learners to organize learning goals, projects, tasks, and notes in one place.

The application combines elements of:

- Project management
- Personal learning management
- Knowledge management
- Developer productivity
- AI-assisted learning

The long-term vision is to allow a user to describe what they want to learn or build and have SkillForge help transform that goal into an actionable learning/project plan.

---

# Target Users

The primary target users are:

- Software developers
- Programming students
- Self-taught developers
- Technical professionals
- People learning new technologies
